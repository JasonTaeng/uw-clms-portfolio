# MIT OCW 24.900 — Introduction to Linguistics — Notes

## What this is
Notes organized around a recurring analysis loop:
**observe data → propose an analysis → test with counterexamples**.

---

## 1) Evidence in linguistics
Common evidence types:
- grammaticality judgments (context-sensitive; can be gradient)
- corpora and usage data
- acquisition data
- psycho-/neurolinguistic evidence
- cross-linguistic comparison

Analysis loop:
1) write the pattern
2) propose a rule/constraint
3) try to break it
4) revise

---

## 2) Morphology
Key units:
- morpheme, affix, stem/root
- grammatical features (tense, number, case, aspect…)

Processes:
- affixation, compounding
- allomorphy, suppletion
- productivity

Mini habit:
segment forms → hypothesize rules → validate against exceptions.

---

## 3) Phonetics and phonology
Phonetics:
- place/manner/voicing as descriptive features

Phonology:
- phonemes vs allophones
- phonotactics, syllable constraints
- common patterns (assimilation, devoicing)

Minimal pairs are a quick contrastiveness check (not the only tool).

---

## 4) Syntax
- sentences are hierarchical structures, not just strings
- constituency tests are heuristics; use multiple tests
- dependencies and movement help explain long-distance patterns
- ambiguity is evidence (same string, different structures)

---

## 5) Semantics
- truth conditions
- entailment / contradiction
- quantification and scope
- compositionality depends on structure

---

## 6) Variation and change (high level)
Variation:
- dialects are systematic
- style shifting / code-switching are structured behaviors

Change:
- sound change, reanalysis, grammaticalization
- studied via comparative evidence and records

---

## 7) Acquisition and signed languages (big picture)
Acquisition:
- generalization → overgeneralization → refinement

Signed languages:
- show language is not tied to speech
- strong evidence for modality-independent linguistic structure

---

## Key terms (10)
- grammaticality judgment
- morpheme
- allomorphy
- phoneme
- allophone
- phonotactics
- constituency
- dependency
- movement
- entailment

## Common confusions (4)
- **prescriptive vs descriptive**: “should” rules vs patterns people actually use
- **constituency tests are not proofs**: they’re heuristics; rely on converging evidence
- **dialect ≠ incorrect language**: dialects are systematic varieties
- **language ≠ speech only**: signed languages are full languages with structure
